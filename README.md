# X.Point Catalog

کاتالوگ عمومی: `index.html`

پنل مستقل گزارش استفاده (بدون ورود): `admin.html`

داده‌های آماری بدون اطلاعات شخصی در برگه «آمار سایت» ذخیره می‌شوند. برای فعال‌سازی یا به‌روزرسانی سرویس، محتوای پوشه `google-apps-script` را در پروژه Apps Script جایگزین و همان Web app را با نسخه جدید Deploy کنید.

تنظیمات جشنواره نیز در همان برگه، محدوده `Q1:X3` قرار دارد؛ با انتخاب وضعیت «فعال»، جشنواره در سایت نمایش داده می‌شود و بازه شروع/پایان اختیاری است.
