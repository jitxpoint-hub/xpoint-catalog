# کاتالوگ محصولات X.Point

این سایت بدون نیاز به پنل مدیریت، فهرست محصولات را از Google Sheets می‌خواند و تصاویر را از Google Drive نمایش می‌دهد. اگر آدرس Sheet تنظیم نشده باشد، داده‌های نمونه‌ی `products.sample.json` نمایش داده می‌شوند.

بنرهای بالای سایت نیز می‌توانند مستقیماً از یک پوشه Google Drive خوانده شوند. راه‌اندازی کامل در فایل `google-drive-banner-setup.md` توضیح داده شده است.

## اجرای سایت

به دلیل محدودیت امنیتی مرورگر برای خواندن فایل JSON، پوشه را با یک وب‌سرور ساده اجرا کنید:

```powershell
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید. برای انتشار عمومی می‌توان کل پوشه را روی هر سرویس میزبانی استاتیک قرار داد.

## اتصال به Google Sheets

1. فایل `product-template.csv` را در Google Sheets وارد کنید یا سطر اول آن را عیناً بسازید.
2. ستون‌ها را نگه دارید: `نام محصول`، `برند`، `کد محصول`، `قیمت نقد`، `دسته‌بندی` و `عکس`.
3. از مسیر **File → Share → Publish to web** شیت محصولات را با فرمت CSV منتشر کنید.
4. لینک CSV را کپی و در فایل `config.js` مقابل `googleSheetCsvUrl` قرار دهید.

نمونه:

```js
window.XPOINT_CONFIG = {
  googleSheetCsvUrl: "https://docs.google.com/spreadsheets/d/e/.../pub?output=csv",
  fallbackDataUrl: "products.sample.json",
  currencyLabel: "تومان"
};
```

## تصاویر Google Drive

برای هر محصول، تصویر را در Google Drive روی حالت **Anyone with the link** بگذارید. در ستون `عکس` یکی از این دو مقدار قابل استفاده است:

- لینک کامل فایل Google Drive
- فقط File ID فایل؛ مانند `1AbCdEfGhIjKlMnOpQrStUvWxYz`

سایت لینک Drive را به آدرس تصویر مناسب تبدیل می‌کند. بهتر است تصویر محصول مربع، با پس‌زمینه روشن و حداقل عرض ۸۰۰ پیکسل باشد.

## قانون موجودی و نمایش محصول

- اگر ستون `قیمت نقد` عدد داشته باشد، محصول «موجود» محسوب می‌شود و در سایت نمایش داده می‌شود.
- اگر ستون `قیمت نقد` خالی، صفر یا فاقد عدد معتبر باشد، آن محصول به‌طور کامل از سایت پنهان می‌شود.
- برای ناموجود کردن یک محصول لازم نیست ردیف آن را حذف کنید؛ فقط قیمت نقد را خالی کنید.
- برای موجود کردن دوباره‌ی محصول، قیمت نقد را وارد کنید. پس از به‌روزرسانی داده‌ی منتشرشده، محصول دوباره نمایش داده می‌شود.

## دسته‌بندی‌های مجاز

`لوازم خانگی`، `گجت‌های خانگی`، `تلویزیون`، `اسپیکر`، `کنسول بازی`، `لپ‌تاپ`، `تبلت`، `اکسسوری` و `موبایل`.

نام دسته در Sheet باید دقیقاً مطابق این فهرست باشد تا فیلتر دسته‌بندی درست کار کند.
