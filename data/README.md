# پشتیبان فهرست محصولات X.Point

این پوشه نسخه پشتیبان فهرست محصولات کاتالوگ را نگه می‌دارد:

- `xpoint-products.xlsx`: نسخه کامل Excel شامل برگه‌های «محصولات» و «راهنما»
- `products.csv`: نسخه متنی برگه «محصولات» برای بازیابی سریع و بررسی تاریخچه تغییرات

منبع فعلی، شیت جدید X.Point است. گردش‌کار `backup-catalog.yml` هر ۳۰ دقیقه منبع را بررسی می‌کند و فقط در صورت تغییر داده‌ها نسخه جدید را در GitHub ثبت می‌کند.

نکته: قیمت خالی به معنی عدم نمایش محصول در سایت است.
